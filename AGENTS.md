# Repository guidance

Read README.md and docs/ARCHITECTURE.md first. Keep maintainable source, configs, meaningful tests and concise guides. Exclude datasets, credentials, checkpoints, build output and scratch scripts. Curated documentation figures are allowed with provenance.

Document camera axes, radians, timestamps and dy/dx ordering. Geometry changes need sign, identity, bounds, sensor gap and mask alignment checks. Missing labels must not create negative supervision.

Run relevant Python and Android checks. Synthetic checks and saved timings are not road accuracy. Research training requires the researcher's review. Preserve upstream attribution.
